# CS50 Introduction to Artificial Intelligence with Python

This repository contains my complete journey through Harvard's CS50 Introduction to Artificial Intelligence with Python course. Each week focuses on different AI concepts and techniques, implemented through hands-on projects that demonstrate practical applications of artificial intelligence algorithms.

## 🎯 Course Overview

Harvard's CS50 AI course explores the fundamental concepts and algorithms that drive modern artificial intelligence. Through this comprehensive program, I've gained expertise in:

- **Search Algorithms & Problem Solving**
- **Knowledge Representation & Logic**
- **Uncertainty & Probabilistic Models**
- **Optimization Techniques**
- **Machine Learning & Neural Networks**
- **Natural Language Processing**

## 📚 Weekly Projects & Skills Developed

### Week 0: Search
**Projects:** `degrees` • `tictactoe`

**Key Concepts:**
- Breadth-First Search (BFS) & Depth-First Search (DFS)
- Informed Search Algorithms (A* Search)
- Adversarial Search & Minimax Algorithm
- Alpha-Beta Pruning

**Skills Gained:**
- **Degrees**: Implemented BFS to find the shortest path between actors through their movie connections (Six Degrees of Kevin Bacon)
- **Tic-Tac-Toe**: Built an optimal AI player using minimax algorithm with alpha-beta pruning

### Week 1: Knowledge
**Projects:** `knights` • `minesweeper`

**Key Concepts:**
- Propositional Logic & Knowledge Bases
- Logical Inference & Model Checking
- Constraint Satisfaction Problems

**Skills Gained:**
- **Knights**: Solved logic puzzles using propositional logic and automated reasoning
- **Minesweeper**: Implemented an AI that uses logical inference to safely navigate minefields

### Week 2: Uncertainty
**Projects:** `pagerank` • `heredity`

**Key Concepts:**
- Probability Theory & Bayes' Rule
- Bayesian Networks & Inference
- Markov Models & Random Sampling

**Skills Gained:**
- **PageRank**: Implemented Google's PageRank algorithm using both sampling and iterative approaches
- **Heredity**: Built a Bayesian network to calculate genetic trait inheritance probabilities

### Week 3: Optimization
**Projects:** `crossword`

**Key Concepts:**
- Local Search Algorithms
- Constraint Satisfaction Problems
- Backtracking & Arc Consistency

**Skills Gained:**
- **Crossword**: Developed an AI system that generates crossword puzzles by solving complex constraint satisfaction problems

### Week 4: Learning
**Projects:** `shopping` • `nim`

**Key Concepts:**
- Supervised Learning & Classification
- Reinforcement Learning & Q-Learning
- Decision Trees & Neural Networks

**Skills Gained:**
- **Shopping**: Built a machine learning model to predict customer purchase behavior using scikit-learn
- **Nim**: Implemented a reinforcement learning agent that masters the game of Nim through Q-learning

### Week 5: Neural Networks
**Projects:** `traffic`

**Key Concepts:**
- Deep Learning & Convolutional Neural Networks
- Image Recognition & Computer Vision
- TensorFlow & Keras Implementation

**Skills Gained:**
- **Traffic**: Created a deep learning model using TensorFlow to classify traffic signs with high accuracy

### Week 6: Language
**Projects:** `parser` • `attention`

**Key Concepts:**
- Natural Language Processing
- Context-Free Grammars & Parsing
- Attention Mechanisms & Transformers

**Skills Gained:**
- **Parser**: Built a natural language parser that extracts noun phrases from sentences using context-free grammars
- **Attention**: Implemented attention mechanisms for sequence-to-sequence models in natural language processing
